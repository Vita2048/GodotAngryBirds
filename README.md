# Premium Angry Birds Godot Port

Godot 4.6.2 recreation of the original `Vita2048/AngryBirds` canvas game.

## Run

Open this folder in Godot 4.6.2 and run `res://scenes/Main.tscn`.

## Controls

- Drag the loaded bird on the slingshot and release to launch.
- Click during flight or press Space to use a bird ability.
- Medium bird splits into two extra birds.
- Large bird boosts forward.
- Use Restart from the top-right during a level.

## Notes

- Original SVG scenery assets are copied into `res://assets`.
- The five original campaign levels are ported into `scripts/Game.gd`.
- The original browser level editor is not ported; this build focuses on the native Godot campaign and premium presentation.
